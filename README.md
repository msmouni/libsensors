# LibSensors

LibSensors is the common sensor-handling library used across the Pi-Home ecosystem.

It provides shared sensor abstractions and functionality so that different sensor implementations can use a consistent model across different hardware and platforms.

It is used by both [pi-home-sensors](https://github.com/msmouni/pi-home-sensors) on Raspberry Pi and [sensors-node](https://github.com/msmouni/sensors-node) on ESP32-C3 devices.
